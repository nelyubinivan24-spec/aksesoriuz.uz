# Aksessoriuz Site Rebuild

New website project for Aksessoriuz: a complete redesign and rebuild focused on B2B lead generation, premium product presentation, SEO, performance, and scalable catalog management.

## Project Goal

Create a modern commercial website that preserves the company's core business while improving:

- lead generation and conversion paths;
- product and service structure;
- brand perception and trust;
- SEO and technical quality;
- catalog scalability;
- mobile UX.

## Working Method

The project is developed in controlled stages. Each major stage produces reviewable artifacts, receives approval, and then moves into implementation.

Core methodology:

1. Strategy before design.
2. Conversion architecture before page production.
3. Content models before catalog migration.
4. Design system before full UI rollout.
5. Git-backed changes with reviewable branches.

## Current Status

Stage 0 is in progress: repository setup and project documentation.

## Proposed Technical Direction

- Astro
- TypeScript
- React islands for interactive components
- Tailwind CSS
- Lucide icons
- Static/catalog-first content model
- SEO-ready routing, sitemap, canonical URLs, OpenGraph, and Schema.org

Final stack decisions are documented in `docs/TECHNICAL_DECISIONS.md`.
